# 高考英语词汇库

一套可直接用于背单词 App / 打印的高考英语词库。六个文件夹，每个文件夹内是同一本书的 **XML 词库** 与 **PDF 词表**。

## 目录结构

| 文件夹 | 词条 | PDF 页数 | 说明 |
|---|---:|---:|---|
| `words/` | 2,252 | 48 | 核心版：课标词中剔除基础词 |
| `words_full/` | 3,810 | 80 | 全量版：课标词全收 |
| `words_extra/` | 345 | 8 | 拓展版：真题、联考与讲义里的课标外词 |
| `words_short/` | 2,252 | 48 | 核心版·精简 |
| `words_full_short/` | 3,810 | 80 | 全量版·精简 |
| `words_extra_short/` | 345 | 8 | 拓展版·精简 |

每个文件夹内：

- `gaokao3600.xml` —— 词库数据
- `gaokao3600.pdf` —— 打印用词表（仅正文）
- `example.xml` —— 格式模板

## 词条格式

```xml
<?xml version="1.0" encoding="utf-8"?>
<wordbook name="高考必背3600词" count="3810" level="full" ...>
  <word en="abandon" pos="vt. / n." zh="抛弃，舍弃，放弃" phonetic="ə'bændən" />
</wordbook>
```

| 属性 | 含义 |
|---|---|
| `en` | 词目（原形，按字母序） |
| `pos` | 词性 |
| `zh` | 中文释义，`；` 分隔义项 |
| `phonetic` | 英式国际音标 |
| `freq` | 仅拓展版：在真题语料中未加注释出现的次数，`0` 表示仅见于讲义 |

根节点的 `level` 区分版本（`core` / `full` / `extra`，带 `-short` 为精简版）。

## 版本差异

- **核心版**：从 3,810 条中剔除 CEFR A1–A2（小学至初中）基础词 1,558 条，留高中段核心词。
- **全量版**：不删减，供通读与查漏。
- **拓展版**：来自 2021–2025 年 42 套高考真题、3 套联考卷、20 份老师讲义；只收课标外、真题中未附汉译的词。讲义词条标 `src="讲义"`。
- **精简版**：词性最多 2 个、释义最多 3 条，其余与对应完整版一致。
